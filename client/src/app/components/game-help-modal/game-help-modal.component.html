Comment jouer

🎯 Comment Gagner

  • Mode classique : le premier joueur a gagner 3 combats remporte la partie.
  • Capture du drapeau (CTF) : vous gagnez en ramenant le drapeau a votre point d’apparition.
  • En CTF, quand un joueur reussit, toute l’equipe gagne.

🎮 Controles

  • Deplacement : utilisez W, A, S, D.
  • Clic gauche : choisissez une cible ou interagissez avec une case.
  • Clic droit : inspectez une case ou un joueur.
  • Utilisez d’abord le bouton Action, puis cliquez sur une cible valide.

🧭 Bases du Jeu

  • A chaque tour, vous avez des points de mouvement et une action.
  • Vous vous deplacez sur des cases adjacentes seulement, sans diagonales.
  • Selon le terrain, certaines cases coutent plus ou moins de mouvement.
  • Vous pouvez attaquer, utiliser des portes, activer des sanctuaires ou interagir avec le drapeau.

🚩 Capture du Drapeau (Regles CTF)

  • Marchez sur le drapeau pour le ramasser.
  • Vous pouvez transferer le drapeau a un allie proche ou envoyer une demande.
  • Votre coequipier doit accepter le transfert pour qu’il se fasse.
  • Vous ne pouvez pas attaquer vos coequipiers en CTF.

⚠️ Regles Importantes

  • Le chrono fait avancer le tour. Agissez avant la fin du temps.
  • Si un joueur quitte, son personnage abandonne la partie.
  • Vous avez une seule action par tour, choisissez-la bien.
  • Certaines interactions peuvent bloquer temporairement le mouvement jusqu’a votre reponse ou leur fermeture.
